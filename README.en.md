# Jiankang Public Communication Editor

An independent Codex Skill-only plugin for adapting rigorous Chinese professional content to WeChat Official Accounts without sacrificing author sovereignty, factual boundaries, or claim strength.

The plugin provides one orchestrator and four specialist Skills for topic framing, channel adaptation, publication packaging, and evidence-aware performance review. It can work alone or hand unstable source material to the optional Chinese Writer AI Assistant.

## Install

```bash
codex plugin marketplace add chmask/jiankang-public-editor --ref v0.1.0
codex plugin add jiankang-public-editor@jiankang-public-editor
```

Start a new Codex task after installation or upgrade, then invoke `$orchestrate-public-communication` with your manuscript and publication goal.

Version 0.1.0 has no backend, MCP server, account database, WeChat credentials, or automatic publishing. It does not promise virality or invent facts, sources, metrics, feedback, or causal explanations. See the [Chinese README](README.md) and [usage manual](docs/usage-manual.md) for the full contract.
