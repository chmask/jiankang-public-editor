# LinkedIn 英文质量与发布适配
适用版本：0.2.0。平台来源核对日期：2026-10-06。

## 不可退让的质量标准
保留事实、限定语、引语归属和因果强度。专业术语前后一致；歧义必须标记，不能靠流畅表达消除。中文“我们”逐项确认指代，不能变成作者公司的成果。不得虚构作者经历、客户、职业身份、成绩、对话或读者反馈。英文应自然、具体，避免直译腔、泛泛商业套话；有作者认可的英文样本时优先参考，没有样本不声称已经建立英文声纹。
跨文化背景仅使用用户提供或已经核验的材料；缺口标记待补。医疗、法律、财务等结论保持原有证据边界。不得将中文上游 Skill 描述为英文专业审校。

## 平台与内容双向优化
先做内容→包装映射：列出核心判断、支持材料、限定与适用范围，再判断开篇、标题、视觉文字和行动能承诺什么。
再做平台→内容适配：选择 post、article、newsletter edition 或 companion_post，检查读者背景、形式容量、开篇信息、段落阅读路径、媒体与正文一致性、来源可达性及行动目的。
发现形式不匹配时，优先缩小包装承诺、建议更合适形式；需要补证据、改变立场、大幅删改或重组正文时，交回英文改编阶段并列作者决定，不在包装阶段擅自改变正文。
交付“平台要求/建议 → 正文依据 → 包装选择 → 缺口或作者决定”的简短核对记录。不要求每项都是问题。
技术硬限制与编辑建议分开。准确字符数、媒体尺寸、账号可用功能等发布时从官方帮助或实际编辑器确认；未核验标“发布前核验”，不用过期数字充当强制规则。不给所谓最佳字数、发布时间、标签数量或算法诀窍以确定承诺。
动态帖用自然段，长文可用标题；正文不默认一行一句，不用 Unicode 仿粗体替代原生排版。不套用公众号摘要、朋友圈转发等字段。讨论问题必须具体且可回答，不默认 Agree?、comment to agree、标签堆砌或互动诱饵。
Newsletter 仅支持单期内容与配套帖，不虚构系列历史或执行订阅运营。
