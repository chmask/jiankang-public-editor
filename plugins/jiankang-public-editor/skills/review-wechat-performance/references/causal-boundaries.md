# 传播复盘的因果边界

## 观察不等于原因

相关不等于因果。一次指标变化可能同时受标题、发布时间、流量来源、选题、内容形式或格式、读者匹配、账号规模、外部事件和平台分发影响。没有设计对照时，把它们保留为竞争解释。

一次公众号文章不能证明稳定传播规律，也不足以得出“某类标题一定有效”“某时段最佳”或“读者不喜欢长文”等普遍结论。连续观察可以提高信心，但仍要检查口径、样本和其他变化。

## 从解释到假设

可能解释必须说明：

- 它能解释哪些观察；
- 哪些观察与它不一致；
- 还有哪些竞争解释；
- 下一次改变什么或记录什么才能区分它们。

每轮最多提出三项假设，优先选择影响大、可验证且不损害事实和作者声纹的改变。不要同时改变标题、开篇、发布时间和流量入口后再声称知道哪个因素有效。

## 读者反馈

读者原话使用引号时必须逐字保留，并标明来源范围；为了保护隐私可以匿名。对多条反馈进行转述或归纳时必须明确标明，不把少数意见写成全体读者共识。

反馈的存在能说明某些读者如何反应，不能单独证明文章对所有读者的影响，也不能替作者虚构没有出现的正面评价。
