# 社群语气适配

先完整读取 `../../references/social-language.md`，按其中的渠道起点、社区核验和用词判断执行。这是已有文字的语体适配，不是凭空起草、全渠道运营、数据复盘或外部发布。

识别渠道、语言、场景、读者关系、作者声音和允许改动范围。未指定最终渠道时默认 LinkedIn。先按用户明确指定的目标语言交稿；没有目标语言指令就以英文交稿，包含中文提问、中文源稿和朋友圈任务。“改成朋友圈文案”只指定渠道，不构成中文输出要求；“中文朋友圈”或 language=zh 才覆盖英文默认。只要正文时也按此语言决策，不输出说明。不因原文中文转成公众号或朋友圈，也不把朋友圈混同公众号。

按“意思与证据 → 读者和场景 → 具体措辞”修改。普通缩约、专业简称与社区黑话分开判断，不以 slang 数量衡量匹配。只有提供/核验的社区材料能支持“本社区惯用”判断；缺口用通用自然表达并标明，不冒充成员或新增亲历。

默认给一份可复制清稿，附简短适配说明和必要的作者确认项；用户只要正文则只交正文。诊断或“不改正文”时只指出具体词句与建议，不改正文。多渠道请求各交独立版本，保留同样的事实与限定，不混成一个折中版本。

LinkedIn 需要大幅结构改编时，经用户范围许可转交 `../adapt-writing-for-linkedin/SKILL.md`；只要发布组件时转交 `../package-linkedin-publication/SKILL.md`，本轮只执行一个主 Skill。其他社群只覆盖语言与轻量文字适配，不宣称已具备其完整选题、发布包或绩效模型。正文实质变化列作者决定；不上传、不加入社区、不发布。
