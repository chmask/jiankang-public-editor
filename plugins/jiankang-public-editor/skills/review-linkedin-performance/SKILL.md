# LinkedIn 传播复盘
先完整读取 ../../references/linkedin-quality.md。
使用真实内容、统计窗口、账号定位、发布形式及平台指标定义。保留用户提供数据原值；百分比必须写分母，曝光不等于读完，互动不等于业务结果。
输出观察、可比基线、可能解释、未知、最多三项下一轮假设和验证所需数据。缺窗口或分母先指出；安全部分可继续，不补造。
个人账号与机构账号、post 与 article、Newsletter 不直接混比。平台字段名称或指标口径未核验时标记，不把缺失数据当零。
检验内容承诺是否兑现、读者专业匹配、开篇与正文一致性；标题、分发、作者网络、话题、时机等保留竞争解释。一次结果不能证明因果。
下一轮假设应改变有限变量；不优化虚假互动，不自动发评论、拉取私密数据或修改账号。不承诺曝光、获客或涨粉。
