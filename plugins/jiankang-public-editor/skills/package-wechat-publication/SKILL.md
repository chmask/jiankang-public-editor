# 发布包装

围绕稳定稿生成能够由正文兑现的发布组件。每次读取 `references/publication-package.md`；需要生成或比较标题、摘要与开篇时，再读取 `references/title-and-opening.md`。

## 开始前

确认正文已经稳定到足以承担标题和摘要承诺。若正文无法兑现预期承诺，返回传播统筹进行选题立意、渠道改编或上游编辑交接，不用更强的包装掩盖内容缺口。

已有账号语境、目标读者和传播目标时直接使用；没有但可以由本次任务安全推断时标明临时假设。不同答案会改变标题方向时，只询问最关键的信息。

## 工作范围

- 生成主标题和有限备选；
- 写摘要、封面短文案和必要的正文导语；
- 设计一个与文章目标一致的文末行动；
- 写可直接使用的朋友圈转发文字；
- 列出作者需要确认的事实、语气和传播风险。

不广泛重写正文。发现正文局部问题时标出位置和建议去向，不在包装阶段擅自吸收高风险修改。

## 外部边界

本 Skill 不登录公众号、不上传素材、不创建草稿、不公开发布。即使环境中存在相应工具，也不能声称已经发布或发布成功，除非用户另行授权并由实际工具返回可验证结果。

输出发布包时，把可复制内容与解释、风险和传播假设分开。没有必要的字段可以说明理由后省略，不以数量制造专业感。
