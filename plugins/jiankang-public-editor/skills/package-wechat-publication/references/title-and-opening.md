# 标题、摘要与开篇

## 标题原则

标题必须准确、具体，并由正文支持。为每个候选标题指出正文中的依据，检查读者进入文章后能否由正文兑现承诺。

可以从问题、判断、实用价值、反常识、人物或情境六种角度强调真实内容。角度是选择重点，不是提高论断强度。

不得夸大确定性、普遍性、风险、收益或权威性，不把个案写成普遍规律，不把可能性写成结果，不把作者解释包装成已经证实的事实。“震惊”“真相”“所有人都错了”等词只有在正文真实、具体且不可替代地支持时才可能使用，不能作为默认刺激手段。

主标题只选一个。备选标题二至四项，每个备选说明它强调的真实价值、适合的读者动机和可能牺牲的信息。原题已经准确有力时可以保留原题，不为了交付数量强行替换。

## 摘要

摘要帮助读者判断文章是否与自己有关，应概括问题、核心价值或主要判断，不重复标题，不提前夸大结论。摘要中的事实和数字必须来自正文或用户提供的材料。

## 正文导语

只有稳定稿的现有开篇确实阻断目标读者进入时才建议导语。导语可以说明问题、情境或阅读收益，但不能虚构个人经历、读者心理、紧迫性和公共事件。已经有效的原开篇直接保留。
