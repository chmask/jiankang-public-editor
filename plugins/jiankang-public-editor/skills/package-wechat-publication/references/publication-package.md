# 标准发布包

## 默认结构

按任务需要输出以下字段：

1. **主标题**：一个，正文能够兑现；
2. **备选标题**：二至四项，说明各自强调的真实价值；
3. **摘要**：用于公众号摘要栏的可复制文字；
4. **封面短文案**：与标题互补，不重复制造第二个标题；
5. **正文导语**：只有原开篇需要补充时提供；
6. **正文稳定稿**：用户要求完整发布包且已有稳定稿时原样附上，或明确引用当前稳定版本；
7. **文末行动**：一个主要行动，选择收藏、转发、关注、留言或具体外部行动中最符合文章目标的一项；
8. **朋友圈转发文字**：可以直接复制，说明分享理由，不冒充他人反馈；
9. **作者确认项**：事实、语气、标题承诺、链接和外部行动风险；
10. **传播假设**：本次包装希望验证的一项变化及需要观察的数据。

字段不适用时可以省略，但要在发布包之外说明省略理由。不要用空泛套话凑满十项，也不要在可复制字段中混入编辑说明。

## 文末行动

默认只设计一个主要行动。文章以建立理解或长期信任为目标时，不强迫读者转发、关注和留言同时发生。行动语言自然、具体，不制造羞耻、恐惧或虚假的群体压力。

## 朋友圈转发文字

转发文字说明作者为什么写、读者可能获得什么或文章讨论了什么。保留作者口吻，不写“很多人问我”“读完都沉默了”等没有真实依据的社会证明。

## 工作说明

标题比较理由、事实风险、作者确认项和传播假设属于工作说明，与最终可复制内容分开。发布包完成不等于已经上传、创建微信草稿或公开发布。
