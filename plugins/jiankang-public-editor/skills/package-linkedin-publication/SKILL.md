# LinkedIn 发布包装
先完整读取 ../../references/linkedin-quality.md。
基于稳定正文进行平台与内容双向优化。先确定形式、作者/机构发布身份、读者与目的；不能把 post、article 与 Newsletter 套成同一发布包。
输出可复制发布组件以及分开的适配记录和作者确认项：
- post：适合正文的开篇；正文稳定版本说明；必要且具体的行动/讨论问题；真实存在链接的说明。
- article / newsletter edition：由正文兑现的标题、必要摘要或导读、配套动态帖及必要封面短文案。单期 Newsletter 不等于建立订阅体系。
- companion_post：原文链接或待补链接、文章价值的具体说明、可选讨论问题，不虚构原文内容。
只生成实际需要的组件。标签、提及、图片文字仅在相关且真实时建议；不固定数量、不伪造账号或链接、不声称已制作图片。
执行“核心判断→支持→限定→组件承诺”检查，再执行“平台形式→读者路径→组件选择”检查。交付简短对应记录，指出包装适配收益和内容代价。
正文不足以支持强标题时给保守可用版本，并把补证据或重组建议列为作者决定。未获正文修改授权不重写正文；有授权仍应交给英文改编阶段处理实质修改。
精确平台限制未核验时标发布前核验；推荐策略不得写成算法保证。发布包准备好不等于公开发布。
