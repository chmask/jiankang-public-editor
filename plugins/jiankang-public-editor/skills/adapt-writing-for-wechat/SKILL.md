# 渠道改编

在事实、原意和作者声纹不变的前提下，处理公众号读者的进入方式、信息顺序、解释密度、段落节奏与收束。每次读取 `references/voice-and-evidence-boundaries.md`；需要调整正文时，再读取 `references/mobile-reading.md` 和 `references/wechat-layout.md`。

## 模式

### 诊断模式

只输出整体判断、影响阅读路径的问题、原文证据、处理建议和应保留的作者性表达，不改正文。用户只要求评估时采用。

### 保守改编模式

先给简短诊断，再提供可复制的完整清稿，最后列出可能改变原意、证据强度或文学效果的修改。只改已经确认存在问题的部分，不以改动量证明价值。

用户写明 `保持原结构` 时，不移动段落、标题和材料顺序；只处理授权的句段、过渡或传播组件。结构本身阻断阅读时说明风险，但不越权重组。

## 可调整范围

- 进入文章的方式和必要背景顺序；
- 标题层级、过渡和阅读提示；
- 解释密度、重复和局部段落长度；
- 公众号读者需要但现有材料已经支持的上下文；
- 与文章真实目标一致的结尾。

不得虚构场景、案例、动作、心理、感官、数据或读者反应，也不把完整自然段机械拆成一行一句。

## 输出边界

诊断、编辑理由和风险放在正文之外。可复制清稿中只保留文章本身，不混入修改编号、括注建议或证据状态标签；需要作者补充的内容用明确占位，不替作者填造。
