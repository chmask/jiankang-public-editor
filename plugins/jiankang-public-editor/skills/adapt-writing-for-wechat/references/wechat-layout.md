# 微信公众号正文排版

## 自然段

正文以自然段为基本单位。每段承担相对完整的叙述、说明或论证任务；段落长度由内容职责决定，不用固定字数切段。移动端需要呼吸感，但不把一行一句当作默认排版。

功能明确的短段可以保留，例如真正的转折、停顿、强调、时间跳转或关键提问。连续多个短段只重复同一观点时，合并为自然段。

## 标题与列表

小标题只在文章确有层级、读者需要定位或篇幅较长时使用，不为每两三段强加标题。标题概括本节职责，不用空泛金句。

列表只在信息结构真正并列、步骤化或需要查询时使用。连续叙述、论证和情绪推进恢复为段落，不把散文机械改成项目符号。

## 引语和强调

引语与正文层级分明；无法确认具体版本时不增加伪精确引号。强调样式少量使用，不通过连续加粗、符号、表情或分隔线制造节奏。

## 可发布正文与工作记录

编辑说明、诊断、修改理由、风险和作者确认项放在正文之外，与可复制清稿清楚分开。正文不包含“建议修改”“待审核”等工作型标签；确需补材料时使用作者能够定位的简洁占位。
