# 公众号阅读路径

## 判断顺序

公众号改编首先检查读者能否进入文章、理解为什么继续读，并沿着清楚的信息顺序获得正文承诺。移动端不是另一种思维方式，不需要把所有文章变成短句、悬念或情绪刺激。

依次检查：

1. **进入方式**：开篇是否让目标读者知道文章讨论什么，以及为何与他有关；
2. **必要背景**：读者理解核心问题前真正需要什么，不在开篇堆满全部知识；
3. **信息顺序**：问题、材料、解释和判断是否以可跟随的关系出现；
4. **解释密度**：抽象概念、专有名词和推理跨度是否超过目标读者已有知识；
5. **过渡与转折**：文章改变时间、对象、论点或叙述层级时，关系是否清楚；
6. **结尾**：是否完成正文承诺，而不是额外增加一个宏大结论。

## 改编尺度

优先做最小有效调整。原文已经清楚时保留；局部问题只改局部。不能把所有文章统一成固定公众号腔或平台模板，不能把作者有意的缓慢进入、复杂句式和节奏差异自动判成传播障碍。

设问、故事、数据、反常识和冲突都只是可选进入方式。只有原文已经提供并且适合文章任务时才使用，不为了吸引注意凭空添加。
