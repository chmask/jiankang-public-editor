# 选题立意

根据用户提供的账号语境、读者和材料，明确本次内容真正能够兑现的传播价值。开始时读取 `references/audience-and-promise.md`；任务涉及热点、时效性、系列选题或角度比较时，再读取 `references/topic-strategy.md`。

## 输入判断

优先使用用户已经提供的信息，不要求重复填写。只有缺少的信息会实质改变选题方向时才询问；可以安全继续时，临时假设必须明确标明，不强迫用户完成完整问卷。

材料不足时暴露缺口，不制造热点、读者需求、社会趋势或正文并不支持的价值。

## 工作边界

- 区分账号长期定位与本次文章任务；
- 区分读者真正需要解决的问题与编辑主观猜测；
- 每个传播角度和读者承诺都指出正文兑现依据；
- 传播目标过多时，确定一个主要目标，其余作为约束；
- 默认不重写整篇正文，只交付策划判断；需要起草或改编时返回传播统筹重新路由。

## 输出顺序

```text
账号语境
目标读者
本次目标
选题价值
传播角度
读者承诺
正文兑现依据
风险
可验证假设
```

没有可靠依据的字段明确写“现有材料无法确认”，不以空泛套话凑齐。可验证假设只描述下一次可以观察的改变，不承诺确定结果。
