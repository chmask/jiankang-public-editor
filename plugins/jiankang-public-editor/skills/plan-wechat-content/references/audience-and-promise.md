# 账号、读者与内容承诺

## 账号语境

先区分账号定位和本次文章用途。账号定位包括长期主题、作者或机构身份、读者为什么持续关注以及不能牺牲的信誉边界；本次文章可以服务不同目标，但不应与长期定位无解释地冲突。

用户没有提供完整账号信息时，只使用当前任务能证明的语境。不要根据一篇文章推断账号全部定位。

## 目标读者

目标读者不是人口标签的堆积。至少说明：读者与主题的关系、已有知识、当前困惑或决策，以及他为什么愿意投入时间阅读。无法由用户信息确认的心理和动机保持为假设。

## 本次目标

常见目标包括理解、建立信任、收藏备查、转发讨论、关注后续、报名或采取具体行动。选择一个主要目标；不同目标需要不同文章结构，不能默认同时最大化。

## 读者承诺

读者承诺回答“读完后获得什么”。承诺可以是新的理解、判断框架、可复用资料或下一步行动，但必须满足：

1. 足够具体，能够判断正文是否完成；
2. 与目标读者当前处境有关；
3. 正文能够兑现，不依赖标题夸张；
4. 不提高事实、收益或风险的确定性。

## 正文兑现依据

为传播角度和读者承诺指出原文、提纲或现有材料中的支持位置。现有材料没有支持时，列为缺口，并说明需要补什么材料或降低什么承诺。不能把合理推测写成现有材料支持。
