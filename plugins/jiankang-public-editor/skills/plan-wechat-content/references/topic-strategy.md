# 选题与传播角度

## 选题价值

判断选题时分别回答：

- 它解决读者的什么真实问题；
- 它提供了什么新的材料、解释、判断或工具；
- 为什么现在值得读；
- 这份价值能否由当前正文兑现。

热点不等于内容价值，也不能替代读者进入文章的真实理由。热点只能作为有证据的现实语境，不能把时间接近、词语相似或公众注意力写成不存在的因果关系。

不得制造或虚构热点、趋势、读者需求、社会共识和所谓“大家都在讨论”。需要外部时效事实但用户没有要求检索时，把它列为待核实语境。

## 传播角度

角度是对真实内容价值的选择，不是换一个刺激说法。可以从问题、判断、材料、人物、情境、方法或现实影响进入。每个候选角度都说明：

- 它突出正文的哪一部分；
- 它对目标读者有什么意义；
- 它会弱化或省略什么；
- 它有哪些事实或声纹风险。

默认推荐一个主角度；只有真实取舍明显时再提供不超过两个备选。

## 材料不足

材料不足时暴露并标记缺口：缺少事实依据、读者信息、时效语境或正文兑现内容分别列出。不要用更宏大的意义、更强的情绪或泛化的时代判断填补材料空白。
