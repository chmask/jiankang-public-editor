# LinkedIn 选题立意
先完整读取 ../../references/linkedin-quality.md。
使用作者身份、目标职业读者、已有材料与本次目的；未知信息只在影响结果时询问，其余标注临时假设。英文输入不自动意味着 LinkedIn，平台明确后才采用本规则。
输出目标读者、本次专业问题、核心判断、内容承诺及支持、建议形式与理由、材料缺口和一个可验证假设。明确哪些是作者观点，哪些有事实支持。
形式覆盖 post、article、companion_post；newsletter 只处理单期。不要为了职业平台强加商业角度。没有材料不能补造市场需求、行业共识或时效。
只策划，不起草全文，不连接账号、不发布。按用户语言解释；英文成稿需求在后续英文改编中执行。
