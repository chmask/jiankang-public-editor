将已验证的公众号标题策划功能纳入正式版，技术调用名为 `$gzh-title-strategist`，共十一个 Skill。普通标题优化、仅诊断、仅比较、完整策略和基于真实账号数据的标题复盘分别交付，继续保护正文、原意与作者语气；不推算点击率或宣称微信推荐触发词。

发布范围为独立 GitHub 仓库与 v0.4.0 标签、用户手册、网站项目介绍和本地正式/仓库/开发安装。沿用已完成的四组独立前向测试与修订复核；本次仅将开发版转为正式版，不增加网站试用适配器、后端、MCP 或自动发布能力。标题 Skill 的 Apache-2.0 许可、固定上游来源及修改说明随安装包保留。

发布前校验和同步结果以本轮实际执行记录为准；不会把 GitHub 推送或网站后台保存当作公开页面已更新的唯一证据。

## 0.4.0-dev.1 公众号标题策划（2026-11-20，本地开发）

新增独立的“公众号标题策划” `$gzh-title-strategist`，插件共十一个 Skill。来源为 liucongg/liucong-skills，固定提交 `19e42a49fbb18bfe496e7d2950754d9d7d68904f`，采用 Apache-2.0；引入四份参考，随目录保留原始许可与逐文件修改标记，详见标题 Skill 内的 UPSTREAM.md。

可直接诊断、生成、改写、比较、排序或基于真实数据复盘公众号标题；普通请求只给少量不同方向，完整策略才展开分组和主观比较。仅比较时不新增标题，仅诊断时不换题；已有准确题目可以保留。不会改正文，不把标题优化扩成整套发布包。

传播统筹先识别显式公众号标题语境，公众号标题专门请求自动进入新增 Skill；标题加摘要、封面等组合仍用原发布包装，无平台的泛标题请求仍默认 LinkedIn。网站试用与其他平台的能力范围不变，本轮不对外发布，不覆盖 0.3.0 正式安装。

上游五账号历史统计未经本项目独立复核，明确仅作历史方法示例，不能作为用户账号基线、当前热点、推荐算法或效果预测。标题模板不得用来补造作者亲历、数字、效果、首创或权威；字数建议不是微信硬限制。

实际基线确认旧版可保守起标题，但没有独立入口；三组独立前向试用已覆盖直接调用、只诊断、自动路由、完整发布包、计划模式、材料不足、上游统计与跨平台冲突。试用发现短正文被重标为摘要，独立审查发现比较模式候选数量边界，均已作定点修订；最终回归与安装记录以运行时之外的 evals/jiankang-public-editor/v0.4-title-results.md 为准。

## 项目定义

“见康公众传播AI主编”是独立插件，负责把专业内容转化为适合微信公众号及 LinkedIn 职业读者的渠道版本。它与中文作家AI助理松耦合协作，但可以独立安装和工作。

技术插件名：`jiankang-public-editor`

首版：`0.1.0`

## 0.1.0 范围

首版包含五个 Skill：

1. 传播统筹 `orchestrate-public-communication`；
2. 选题立意 `plan-wechat-content`；
3. 渠道改编 `adapt-writing-for-wechat`；
4. 发布包装 `package-wechat-publication`；
5. 传播复盘 `review-wechat-performance`。

传播统筹是唯一允许隐式调用的入口；其他四个专业 Skill 默认显式调用。一次编辑阶段只有一个主 Skill。

## 关键产品决定

- 与中文作家AI助理保持独立，防止渠道规则污染书稿编辑规则；
- 中文作家AI助理可用时，通过命名 Skill 和上游编辑交接单协作；
- 不可用时保持降级可用，不模拟已经完成上游专业编辑；
- 标题、摘要和传播角度必须由正文支持并兑现；
- 移动端排版以自然段为基础，不把一行一句当成默认风格；
- 复盘区分观察、比较、可能解释、未知和下一轮假设；
- 写作判断、外部工具和发布权限保持分层。

## 与网站的关系

网站已有 Influence Engine，可以保存内容快照、生成微信 HTML 预览并创建微信草稿。0.1.0 只输出可复制发布包，不直接调用 Influence Engine。未来连接层也必须保留预览、固定快照和明确授权。

网站另设统一的有限在线试用工作台 `/projects/writing-tools/try`。其中见康产品提供四个固定适配器，并与“中文作家AI助理”共用提供商、Turnstile 和匿名每日额度。该网页不是 Codex Skill 运行时，不执行传播统筹、不读取账号档案，也不具备上传、微信草稿或发布权限；插件本体的五个 Skill 和网站试用层保持独立发布。

## 安全边界

不虚构热点、事实、案例、数据、反馈和来源；不提高论断强度；不承诺爆款、阅读量或涨粉；不未经授权上传、创建草稿或公开发布；不模仿在世作者的可识别风格。

0.1.0 不包含 MCP、自动发布或远程后端，也不包含账号档案、自动数据导入和内容日历。
