## 项目定义

“见康公众传播AI主编”是独立插件，负责把专业内容转化为适合微信公众号及 LinkedIn 职业读者的渠道版本。它与中文作家AI助理松耦合协作，但可以独立安装和工作。

技术插件名：`jiankang-public-editor`

首版：`0.1.0`

## 0.1.0 范围

首版包含五个 Skill：

1. 传播统筹 `orchestrate-public-communication`；
2. 选题立意 `plan-wechat-content`；
3. 渠道改编 `adapt-writing-for-wechat`；
4. 发布包装 `package-wechat-publication`；
5. 传播复盘 `review-wechat-performance`。

传播统筹是唯一允许隐式调用的入口；其他四个专业 Skill 默认显式调用。一次编辑阶段只有一个主 Skill。

## 关键产品决定

- 与中文作家AI助理保持独立，防止渠道规则污染书稿编辑规则；
- 中文作家AI助理可用时，通过命名 Skill 和上游编辑交接单协作；
- 不可用时保持降级可用，不模拟已经完成上游专业编辑；
- 标题、摘要和传播角度必须由正文支持并兑现；
- 移动端排版以自然段为基础，不把一行一句当成默认风格；
- 复盘区分观察、比较、可能解释、未知和下一轮假设；
- 写作判断、外部工具和发布权限保持分层。

## 与网站的关系

网站已有 Influence Engine，可以保存内容快照、生成微信 HTML 预览并创建微信草稿。0.1.0 只输出可复制发布包，不直接调用 Influence Engine。未来连接层也必须保留预览、固定快照和明确授权。

网站另设统一的有限在线试用工作台 `/projects/writing-tools/try`。其中见康产品提供四个固定适配器，并与“中文作家AI助理”共用提供商、Turnstile 和匿名每日额度。该网页不是 Codex Skill 运行时，不执行传播统筹、不读取账号档案，也不具备上传、微信草稿或发布权限；插件本体的五个 Skill 和网站试用层保持独立发布。

## 安全边界

不虚构热点、事实、案例、数据、反馈和来源；不提高论断强度；不承诺爆款、阅读量或涨粉；不未经授权上传、创建草稿或公开发布；不模仿在世作者的可识别风格。

0.1.0 不包含 MCP、自动发布或远程后端，也不包含账号档案、自动数据导入和内容日历。
