# Contributing

Keep changes focused on one primary Skill or one shared contract. Preserve factual strength, author sovereignty, and the boundary between writing judgment and external publication permissions.

Examples and fixtures must be authored for this repository or clearly redistributable. Never commit private manuscripts, account analytics, author profiles, credentials, or production logs.

Run `npm test` and the official Codex plugin and Skill validators before opening a pull request. Explain any change to routing, permissions, evidence handling, or user-facing output contracts.
